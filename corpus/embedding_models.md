# Модели эмбеддингов

Модель эмбеддингов превращает текст в числовой вектор фиксированной
размерности так, что тексты с близким смыслом получают близкие по
косинусному расстоянию векторы. В отличие от векторной базы данных, которая
только хранит и ищет уже готовые векторы, модель эмбеддингов отвечает за
сам процесс превращения текста в вектор — векторная БД ничего не знает о
смысле текста, она оперирует уже готовыми числами.

Современные многоязычные модели эмбеддингов (например, bge-m3) умеют
одновременно отдавать несколько представлений одного и того же текста:
плотный (dense) вектор для семантического поиска и разреженный (sparse)
вектор, похожий по духу на классический лексический поиск вроде BM25.
Такие модели часто обучают через self-knowledge distillation — модель
дообучается предсказывать те же relevance-скоры, которые сама же выдавала
на предыдущем шаге обучения, что стабилизирует несколько представлений
одновременно.

В отличие от реранкера, который оценивает пару (запрос, документ) вместе,
модель эмбеддингов кодирует запрос и документ по отдельности — это
позволяет заранее проиндексировать весь корпус один раз, а не пересчитывать
представление документа заново на каждый новый запрос.
