# Векторные базы данных

Векторная база данных хранит эмбеддинги — числовые векторы, представляющие
смысл текста, изображения или другого объекта — и позволяет быстро находить
ближайшие по косинусному или евклидову расстоянию векторы для заданного
запроса. Это основа семантического поиска: два текста с близким смыслом
получают близкие векторы, даже если не пересекаются по словам.

LanceDB — встроенная (embedded) векторная БД: она не требует отдельного
сервера и хранит данные прямо на диске в формате Lance/Arrow, что удобно для
локальных приложений и прототипов. В отличие от полнотекстового поиска по
ключевым словам, векторный поиск находит смысловые совпадения, а гибридный
поиск (dense + sparse) объединяет оба подхода для лучшей точности.
